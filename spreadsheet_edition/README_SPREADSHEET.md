# 『パラレル・ジャパニア：クロニクル』スプレッドシート統合エディション 導入・運用マニュアル

本フォルダ（`spreadsheet_edition/`）は、428型教育サウンドノベル『パラレル・ジャパニア：クロニクル』を**1つのGoogleスプレッドシート内で完全完結して動作させるためのコンテナバインド版プロジェクト**です。

---

## 1. 特徴とメリット

1. **アクセス上限・クォータ問題の完全解消（デプロイ不要）**:
   * Web App公開（1つのURLに生徒全員が集中アクセス）を行わず、生徒各自がスプレッドシートの「コピーを作成」してプレイします。
   * スクリプトは生徒自身のアカウントコンテキストで実行されるため、同時実行数30制限や過剰リクエストによるサーバーパンクが**原理的にゼロ**になります。
2. **端末解像度に応じた「可変ダイアログ枠」の自動生成**:
   * Chromebook（1366×768）、標準ノートPC、大型モニターなど、生徒の画面サイズ（`screen.availWidth`, `screen.availHeight`）を起動時にミリ秒で測定し、最適な枠サイズ（920×520 〜 1200×700）を動的に計算して開きます。
3. **映画館モード（黒染めスクリーン設計）**:
   * モーダルダイアログ（`showModalDialog`）表示中、背後のスプレッドシートが自動で暗転ロックされます。
   * さらにシートのセル背景色を漆黒（`#0a0a0c`）に初期化しておくことで、映画館のようにゲーム画面だけに集中できます。
4. **自シート内での複数セーブデータ・デバッグ機能の完全保持**:
   * スプレッドシートの「プレイ記録」タブに、カタカナ名と4桁パスコードで独立保存。
   * デバッグコマンド（名前「ラーメン」、パスコード「0129」）で全シナリオ・結末・TIPSを即座に解放可能。
   * 教員は「プレイ記録」タブを見るだけで、生徒の到達シーンや獲得トロフィーをリアルタイムに一覧確認・指導できます。

## 2. セットアップ手順（管理者・教員向け）

### ステップ 1: マスター用スプレッドシートの新規作成
1. Google ドライブで [新規] ＞ [Google スプレッドシート] を作成します。
2. タイトルを例として `『パラレル・ジャパニア：クロニクル』マスター` と名付けます。
3. メニューの [拡張機能] ＞ [Apps Script] を開きます。

### ステップ 2: スクリプトIDの取得と `clasp push`
1. Apps Script エディタの左側歯車アイコン [プロジェクトの設定] をクリックします。
2. 表示される「スクリプト ID」（英数字の長い文字列）をコピーします。
3. 本フォルダ内の `.clasp.json` をテキストエディタで開き、`scriptId` に貼り付けて保存します：
   ```json
   {
     "scriptId": "ここにコピーしたスクリプトIDを貼り付け",
     "rootDir": "."
   }
   ```
4. ターミナルで本フォルダへ移動し、`clasp push` を実行します：
   ```bash
   cd spreadsheet_edition
   clasp push
   ```
   ※ これにより、`Code.js`, `index.html`, `launcher.html`, 各シナリオ・CSSモジュールが一括アップロードされます。

### ステップ 3: 映画館モードの初期セットアップ
1. スプレッドシートの画面に戻り、ページを再読み込み（F5）します。
2. 数秒後、上部メニューバーの右側に **「🎮 パラレル・ジャパニア」** という専用メニューが現れます。
3. メニューから **「🎬 映画館モード（シート漆黒化・案内設定）」** をクリックします。
   * ※初回実行時のみ、Googleの標準認証画面「承認が必要です（続行 ＞ アカウント選択 ＞ 詳細 ＞ 安全ではないページに移動 ＞ 許可）」が表示されますので、画面の指示に従って許可してください。
4. これにより、スプレッドシートが漆黒の案内スクリーン画面に整い、「プレイ記録」タブも自動生成されます。

## 3. 生徒への授業配布方法

### 方法 A: Google Classroom での配布（推奨）
1. Google Classroom の [授業] ＞ [課題を作成] を開きます。
2. 作成したマスタースプレッドシートを添付します。
3. 添付の権限を **「各生徒にコピーを作成」** に設定して課題を投稿します。
4. 生徒が課題を開くと、生徒自身のドライブに専用のスプレッドシートが自動複製され、自分専用のゲーム環境としてプレイできます。

### 方法 B: 「コピーを作成」リンクでの配布
1. マスタースプレッドシートの共有設定を「リンクを知っている全員（閲覧者）」にします。
2. スプレッドシートのURLの末尾（`/edit...`）を **`/copy`** に書き換えます。
   * 例: `https://docs.google.com/spreadsheets/d/XXXXXXXXX/copy`
3. このURLを生徒に配布（Teams, Google Meet, プリント等）すると、生徒がアクセスした瞬間に「コピーを作成しますか？」という画面が表示され、ワンクリックで個人用シートが生成されます。

---

## 4. 生徒のプレイ手順

1. 配布されたスプレッドシートを開きます。
2. 上部メニューの **「🎮 パラレル・ジャパニア」 ＞ 「▶ ゲームを起動（画面に自動フィット）」** をクリックします。
   * （手動でサイズを選びたい場合は「大画面枠」「標準枠」「Chromebook枠」を選択可能）
3. 端末の画面サイズに応じた最適な可変枠でゲーム画面が表示され、背後のスプレッドシートが暗転します。
4. スタート画面でプレイヤー名（カタカナ）を入力すると、4桁のパスコードが発行されてゲームが始まります。
5. 途中で終了したい時は、画面右上の **「✖ シートへ戻る」** ボタンを押せば、いつでもスプレッドシートに戻ることができます。

## 5. 日常の運用・シナリオ更新コマンド

親リポジトリでシナリオやTIPSを改訂した際、以下のスクリプトを実行することで、子フォルダへ最新データを安全に同期・プレビューできます。

* **最新モジュールの同期**:
  ```bash
  node spreadsheet_edition/sync_from_main.js
  ```
* **ローカルプレビューの生成**:
  ```bash
  node spreadsheet_edition/build_preview.js
  ```
* **全分岐・因果・BAD END健全性チェック**:
  ```bash
  node simulate_all_paths.js
  ```
