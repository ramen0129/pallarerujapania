### 2.2 【課題2対応】11:00開始時の読了本文スキップ
* **対象ファイル**: [`js_engine.html`](file:///c:/Users/佐々木篤史/Desktop/pallarerujapania/js_engine.html)

#### A. 発生原因の解消ロジック
* 現在：`launchNode("A_1100")` が呼ばれると、`currentParagraphIndex = 0` となり、1行目から画面タップを要求される。
* 改善：
  ```javascript
  // launchNode 内の段落初期化処理
  var isHourStartNode = (nodeId === "A_1100" || nodeId === "B_1100" || nodeId === "C_1100");
  var isAlreadyVisited = (state.visitedNodes.indexOf(nodeId) !== -1);
  var prog = TimelineState.getHourProgress();

  if (isHourStartNode && isAlreadyVisited && prog.hour1.allClear) {
    // すでに第1アワー終端で読了済み、かつ第2アワーが解禁されている場合：
    // 即座に全段落を展開し、最下部の第2アワー決断選択肢を表示する！
    skipToChoices();
  } else {
    // 初回プレイ時は通常通り1段落目からタップ進行
    renderCurrentNode();
  }
  ```

### 2.3 【課題3対応】予告編ボタンと選択肢エリアの完全分離
* **対象ファイル**: [`js_engine.html`](file:///c:/Users/佐々木篤史/Desktop/pallarerujapania/js_engine.html), [`index.html`](file:///c:/Users/佐々木篤史/Desktop/pallarerujapania/index.html)

#### A. 選択肢ラッパーの純化
* `choicesWrapper`（選択肢コンテナ）内には、**主人公の主観的行動決断（`node.choices`）のみを描画**し、予告編ボタンなどのシステム系ボタンを同列混在させない。
* 選択肢ボタンの角括弧排除（`DIR_02_CHOICE_NO_BRACKETS`）と合わせ、100%純粋なゲームブック・サウンドノベルUIを担保する。

#### B. 予告編バナーの専用エリア化
* ノベル画面の本文最上部、またはタイムスタンプヘッダー（`11:00 地上スラムの出口`）の真下に、**独立した章間バナー領域（`#novelChapterBanner`）** を新設。
* 第1アワー突破済みノードでは、この上部バナーに「🎬 第2アワー予告編を見る」を小さくスタイリッシュに配置。選択肢エリアとは物理的に分離し、誤認・混同を完全に根絶します。
