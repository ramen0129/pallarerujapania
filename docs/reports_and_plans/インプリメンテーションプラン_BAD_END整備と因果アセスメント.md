# 『パラレル・ジャパニア』BAD END到達性完全化＆因果整合性インプリメンテーションプラン

## 1. 概要と背景
全23個のBAD ENDノードに対するAI精読および全ルート静的追跡スキャン（`scratch/check_true_inbounds.js`）の結果、**20個のノードはすでに1〜13本のルートで到達可能**であることが確認されました。
しかし、以下の**3つのノードが流入ルート0件（孤立状態）**となっており、本来想定された428型のバタフライ・エフェクトや教育的ドラマがプレイヤーに届かない状態にあります。

1. **`BAD_04`【特権の檻】**（エレナ 11:15）: 流入 0件
2. **`BAD_05`【消えた反逆の烽火】**（レン 11:30）: 流入 0件
3. **`BAD_15`【消された自我】**（エレナ 11:50）: 流入 0件

本プランは、これら3ノードを『パラレル・ジャパニア_全選択肢・因果波及完全設計仕様書.md』の諸元に基づき正しく接続・整備し、ゲーム全体の因果網を100%完成させるための詳細設計とリスク・アセスメントです。

## 2. 各ノードの整備詳細

### ① `BAD_04`【特権の檻】（エレナ 11:15）
#### 現状の課題と原因
- `B_1115`（タワー裏面メンテナンス口）の選択肢2「タワー全体の防衛送電を落とし、センサーごと無力化する」が、誤って `next: "BAD_12"`（レン視点のBAD END【誤爆の赤い広場】）に直結しています。
- これにより、エレナ視点をプレイ中に突然レン視点（「オレは鉄パイプを握り直し……」）の画面へ強制遷移し、認知的破綻が生じています。
- 本来、送電遮断（`B_NET_CUT`）はエレナ自身は先へ進み、後からレン（11:25/11:30）が広場へ突入した際にドローン暴走で死亡する長距離バタフライ爆弾（`A_1125` 側ですでにチェック処理実装済み）です。
- そして、エレナ自身が保身から潜入を断念する結末こそが `BAD_04`【特権の檻】です。

#### 修正内容
1. `scenario_elena.html` の `B_1115` を3択構成に改修：
   - **選択肢1（正解）**: 「外周センサーの無力化コードを送信し、検問を解除する」 ➔ `next: "B_1120"`, `slot: "B_1115"`, `flagValue: "B_CODE_SENT"`
   - **選択肢2（バタフライ爆弾）**: 「タワー全体の防衛送電を落とし、センサーごと無力化する」 ➔ `next: "B_1120"`, `slot: "B_1115"`, `flagValue: "B_NET_CUT"`（※エレナは進むが、レンが11:30で `BAD_12` に直面）
   - **選択肢3（自己破滅 BAD_04）**: 「やはり無理だ……犯罪者になる恐怖に負け、回線を切断して屋敷へ引き返す」 ➔ `next: "BAD_04"`

### ③ `BAD_15`【消された自我】（エレナ 11:50）
#### 現状の課題と原因
- 流入ルートが0件。
- 仕様書 p.544 および p.614（`LR_03`【認知的相転移カスケード】）において、**「ダニエル10:00で重傷の警備兵の治療を拒絶（`C_DENY_POLICE`）した場合、110分後のエレナ11:50（`B_1150` 手前）で警備兵804に通報され、西翼を完全包囲されて記憶消去される」** という長距離バタフライとして設計されていました。
- しかし現行コードでは `B_1145` から `B_1150` への遷移時に `C_1000` の判定が存在せず、無条件で通過していました。
- また、`BAD_15` のメタデータ（時間 `11:30`、ジャンプ先 `B_1015`）が古いプロットの残骸のままでした。

#### 修正内容
1. `scenario_elena.html` の `B_1145`（西管制室前）の choice に `checkJump` を実装：
   ```javascript
   checkJump: {
     slotKey: "C_1000",
     branches: [
       { value: "C_DENY_POLICE", next: "BAD_15" }
     ],
     defaultNext: "B_1150"
   }
   ```
2. `scenario_climax.html` の `BAD_15` メタデータ・テキストを仕様書および最新ガイドラインに準拠：
   - `time: "11:50"`
   - `jumpTarget: "C_1000"`, `jumpChar: "C"`, `jumpCharName: "ダニエル（社会権）"`
   - テキスト本文: エレナ主観で、胸に医療識別タグをつけた警備兵804に冷徹に通報され、西翼で包囲拘束されて記憶消去室へ送られるドラマ描写。
   - `desc`: 「ダニエルが警備兵の治療を拒絶したため、冷徹さを取り戻した警備兵804に通報され、西翼を包囲されたエレナは記憶消去室へ送られた。」
   - `hint`: 「西管制室前で容赦なく通報した警備兵804。2時間前、スラムの診療所で彼の治療を拒絶してしまった医師はいなかっただろうか……？（ダニエル 10:00）」

1. **`BAD_04`【特権の檻】（平等権・第14条の逆照射）**:
   - 特権階級の温室にとどまることは一見安全に見えるが、それは「他者を差別し搾取するシステムに魂を売り渡すこと」であるという深い倫理的問いを投げかける。
2. **`BAD_05`【消えた反逆の烽火】（自由権・第21条 表現の自由）**:
   - 言論を放棄すれば支配者に都合よく飼い慣らされる（`BAD_05`）。
   - 逆に憎悪と略奪を煽れば公共の福祉（第12条・13条）に反して無辜の弱者を焼き尽くす（`BAD_14`）。

3. **`BAD_15`【消された自我】（社会権・第25条 生存権／医療アクセス）**:
   - 敵味方を問わず生命を救う（ヒポクラテスの誓い／社会権的生存保障）ことが、時空を超えて他者の人権（エレナの平等と自由）を救うという、三大基本的人権の相互依存・調和の美しさを体感させる。
