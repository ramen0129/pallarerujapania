# ゴードン因果リレー・レン能力復活・第2アワー予告最適化 インプリメンテーションプラン

## 1. 概要と目的
本改修は、以下の重大な課題を根本から解消し、428型サウンドノベルとしての時間・空間・感情の因果交錯リアリズムと、公民科教育サスペンスとしての完成度を極限まで高めることを目的とする。

1. **ゴードンの時系列・距離・心理的矛盾の解消**:
   - 11:00に「地上スラム出口（レンの前）」と「労働者配給所前（ダニエルの前）」の2箇所に同時存在していたバイロケーション矛盾を解消。
   - 「レン（11:00遭遇） ➔ エレナ（11:05惨劇と慟哭を目撃） ➔ ダニエル（11:10〜11:15激高乱入 ➔ 11:20ストライキ）」という、ネオ・ジャパニア都市空間設計（水平距離・移動速度）に100%合致した**奇跡の因果リレー**を確立。
2. **レンの特殊能力（パルクール）の復活**:
   - `A_1100` 冒頭において、水門開放に伴う水圧と泥水を、配管跳躍と低空スライディングで切り抜けるダイナミックなアクション描写を追加。
3. **語彙の適正化（略奪の再考）**:
   - 犯罪的な「略奪」単体から、生存権（日本国憲法第25条）を奪われた労働者の痛切な叫び「あいつらの倉庫をぶち破って、奪われた薬もパンも力ずくで奪い返してやらなきゃ気がすまねぇんだよ！！」へと昇華。
4. **Breakthrough（第1アワー突破モーダル）の予告刷新**:
   - 第3アワー（クライマックス・三重ロック）の内容になっていた `modalHour1Preview` の予告テキストを、真の第2アワー（11:00〜12:00：街頭ビジョン電波ジャック、通信デッキハッキング、非暴力座り込みストライキ）の内容へ刷新。

## 3. 変更対象ファイルと具体的な改訂内容

### 3.1 `scenario_ren.html`
- **`A_1100`（11:00 地上スラムの出口）**:
  - 冒頭：水門が軋みを上げて開き始めた瞬間、勢いよく噴き出す水圧と泥水を、配管を蹴った鋭い跳躍と、鉄格子が開ききる前のわずかな隙間への決死の低空スライディングで突破するパルクール身体能力の描写を追加。
  - ゴードン遭遇：地上へ這い出たレンの前にゴードンが駆け寄り、「オレはこれから配給所広場で仲間たちと体を張って時間を稼ぐ。レン、お前はタワーへ登れ！ 街頭ビジョン放送室を奪って、シンの最期の言葉『オレたちの声を響かせろ』を果たせ！」と託して配給所へ走り去る。

### 3.2 `scenario_elena.html`
- **`B_1100`（11:00〜11:05 境界線の中立広場）**:
  - 身分証破棄の直後、広場の路地で特権警備隊が無抵抗の老労働者を無慈悲に射殺する惨劇を目撃。
  - そこへ駆け込んできた**作業服の巨漢（ゴードン）**が、冷たくなった仲間の遺体を抱きしめて天を仰ぎ、獣のような慟哭の絶叫を上げる。
  - 巨漢は溢れる涙を拭いもせず、泥水に転がっていた鉄パイプを万力のような拳で鷲掴みにし、激高した目で配給所広場へと疾走していく姿を目撃する。
  - （※DIR_08 認知境界に基づき、エレナ視点ではゴードンの名前は出さず、描写のみでプレイヤーに直感させる）

### 3.3 `scenario_daniel.html`
- **`C_1100`（11:00 労働者配給所前）**:
  - 11:00時点では、ダニエルが配給停止に動揺・殺気立つ労働者たちと警備隊の間で白衣一枚で対峙・交渉している状況を描く（選択肢：単身前進 vs スクラム防壁）。
- **`C_1110`（11:10〜11:15 中央薬品配給所前）**:
  - ダニエルと警備隊の対峙の中、仲間の血を浴びたゴードンが鉄パイプを振り上げ怒号と共に乱入！
  - ゴードンのセリフ：
    > 「先生！ もう我慢ならねえ！ オーガスト卿の犬どもめ、仲間を虫けらのように撃ち殺しやがった！ あいつらの倉庫をぶち破って、奪われた薬もパンも力ずくで奪い返してやらなきゃ気がすまねぇんだよ！！」
  - ダニエルの制止、エマの涙の叫び、ゴードンの慟哭と鉄パイプの落下、そして3人が腕を組む座り込みストライキへの突入へと繋ぐ。
