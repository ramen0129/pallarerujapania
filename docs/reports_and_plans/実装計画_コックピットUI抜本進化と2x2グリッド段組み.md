# 🚀 『パラレル・ジャパニア：クロニクル』UI/UX抜本刷新・実装計画書
## 司令室コックピット化 ＆ 2×2段組みレスポンシブデザイン

---

### 1. 改革の狙いと全体ビジョン

現在のメインメニューは、スマホ前提の「縦積みレイアウト」と、ログイン後もタイトルロゴや認証タブが画面上部に居座り続ける構造になっていたため、以下の2大課題を抱えていました：
1. **縦スペースの浪費**: 画面上部のタイトルロゴ（約180px）＋タブ（約50px）＋重複調査員バナー（約70px）＝ 計300px がスクロールを強制していた。
2. **PC横幅の未活用**: 横幅が広いPC画面において、横がスカスカに余り、縦だけ下に見切れてスクロールが必要だった。

ユーザーのご提案に基づき、**「ログイン前（認証ゲート）」と「ログイン後（因果管制コックピット）」を完全分離**し、PCでは**横幅を活かした2×2段組み（シンメトリー配置）**へ抜本進化させます。

### 2. 画面レイアウト設計（ビフォーアフター）

#### ① ログイン前（タイトル＆認証ゲート画面）
- タイトルロゴが画面中央に大きく鎮座。
- 「🌸 さいしょから / 🔄 つづきから」の切り替えタブと入力フォームを表示。
- 初めてのプレイヤーやパスコード復元を迷わせないシンプルなランディングページ。

#### ② ログイン後（超時空・因果管制コックピット画面）
- **タイトルロゴ・認証タブは完全に非表示（`hidden`）**。
- **最上部ヘッダー**: 調査員名（アアア）、ID（4645）、TIPS、BAD、🏆栄誉殿堂、データ切替ボタンを集約。

### 3. 実装ステップと影響範囲

#### Phase 1: ヘッダーへの調査員情報・栄誉殿堂の統合（`index.html`）
- ヘッダー（`<header>`）内に `#headerInvestigatorBadge` を新設：
  - 調査員名（`#headerLoginName`）および ID（`#headerLoginPass`）
  - ログアウト・別データ切替ボタン（`#btnSwitchUser`）
- 栄誉殿堂ボタン（`#btnTrophyGallery`）をヘッダー右側の図鑑ボタン群（TIPS/BAD）の並びに正式配置。
- ログイン前は調査員バッジを非表示、ログイン完了時に自動表示。

#### Phase 2: タイトル・認証セクションのグルーピングと動的切替（`index.html`, `js_ui.html`）
- タイトルロゴ（H1）＋新規/継続タブ＋入力ボックスを `<div id="authLoginScreen">` でラップ。
- ログイン成功時（`displayCharSelect` 実行時）：
  - `#authLoginScreen` を `classList.add("hidden")`。
  - `#boxCharSelect` を `classList.remove("hidden")`。
- ログアウト／データ切替時（`#btnSwitchUser` または `#btnLogoHome`）：
  - 逆の切り替えを行い、スムーズに初期認証画面へ戻れるよう安全な導線を確保。

#### Phase 3: 主人公選択パネルの 2×2 レスポンシブグリッド化（`index.html`, `css.html`）
- `#boxCharSelect` の最大幅を `max-w-2xl` から `max-w-4xl lg:max-w-5xl` へ拡大。
- 上部にあった重複バナー（AUTHORIZED INVESTIGATOR）を撤去し、最上部に「超時空・因果管制オペレーション」を配置。
- 主人公カードコンテナを `grid grid-cols-1 md:grid-cols-2 gap-3 sm:gap-4` に改修。
- **クライマックスカードの常時グリッド配置**:
  - これまで `display: none` で隠していたものを、エレナ・ダニエルと同様に **「ロックオーバーレイ（`#lockOverlayClimax`）」** を重ねる方式に変更。
  - 未解放時は半透明サイバーロック（「🔒 全員H2クリアで解放」）として2×2グリッドの右下に美しく鎮座させ、解放時にオーバーレイが外れて点灯する演出に統一。
  - これにより、序盤からクリア後までグリッドが常に完全なシンメトリーを保つ。

#### Phase 4: カード内部レイアウトの最適化（`index.html`）
- 2列になった際、カード1枚あたりの横幅は約400〜500px。
- キャラクターアイコンを `w-20 h-24 sm:w-24 sm:h-28` に最適化し、名セリフ・人権解説・ボタンがカード内に綺麗に収まるFlexレイアウトに調整。

#### Phase 5: スクロールバー完全消去CSSの適用（`css.html`）
- `::-webkit-scrollbar { display: none; }` および `scrollbar-width: none;` を導入。
- マウスホイールやタッチスワイプの操作性を100%担保したまま、Windowsの野暮ったい白いスクロールバーを完全根絶。

#### Phase 6: 全体検証スイートの実行（`DIR_07`）
- `node scratch/test_state_and_rewind.js`（状態遷移テスト）
- `node simulate_all_paths.js`（全156ノード・破損リンク0件）
- `node sync_from_main.js`（17ファイル同期）
- `node build_preview.js`（`local_preview.html` ビルド確認）

### 5. 安全性・後方互換性
- ゲームエンジンの中核（`js_engine.html`, `js_state.html`）のデータ構造・進行フラグには一切手を加えないため、セーブデータやクリア判定へのリスクは皆無です。
- クライマックスカードの起動属性（`data-launch="CLIMAX"`）や各主人公の起動属性（`data-launch="A/B/C"`）はそのまま保持されるため、クリック時の動作は100%保証されます。
